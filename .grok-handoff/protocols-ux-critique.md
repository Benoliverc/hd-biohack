# UX critique — Protocols feels same every day (input for PO redesign)

**Date:** 2026-10-23 (Asia/Hong_Kong)  
**Route:** `/biohack` (local Dev Pro Me #21; Vercel = login wall)  
**Shots:** `/workspace/hd-biohack-ui-failures/ux-review-2026-10-23/protocols-redesign/`  
**Scope:** Critique only — no implementation.

## 1. Why it feels static / samey
- **No “which day”.** Today shows `As of …`; Protocols never does. Birth chip + “Me · Wetteren · 1990…” repeat; that can’t change overnight.
- **Lead is identity, not weather.** “Run your Manifesting Generator OS” will read the same tomorrow. Sky (Hyper, Focus corner, Gate 50) already lives on Today and is not echoed.
- **Same advice ×5.** Daylight / caffeine / Sacral yes / magnesium reappear in lead checklist, Today columns, Do/Don’t, This week habits, emphasize lists, and Natal baseline.
- **“This week” is mislabeled.** Two of three habits are DAILY; one says “for every Type” — feels like a standing pamphlet, not this week’s sky.
- **Natal drowns transit.** “Always-on / permanent” is the longest region; the one SKY · THIS WEEK sentence sits above habit walls. Transit stacks are collapsed, unlabeled, easy to skip.
- **No completion loop.** ☐ rows have no date, 0/n, streak, or done state — nothing to come back for.
- **Formulary voice.** “(consider adding)” + ignored owned zinc → not “what *you* take today.”
- **One beige rhythm.** No morning-vs-now cue; Refresh has no generated-at stamp.

## 2. What would make tomorrow feel rewarding
- **Hero = today’s delta.** Open with Indication strip (Energy · Space · Main action) + “as of” + 1–2 gates that moved — not Type OS.
- **One checkable Today list** with persisted done + soft “3/3 · come back at midday.”
- **“New this morning”** chip when Refresh finds a different sky/bridge than yesterday (even one line).
- **Owned inventory first** in timed slots; demote “consider adding” below the fold.
- **Week = 1 theme + 1 sky note**, not a second copy of daily habits.
- **Contrast with Today:** Today = weather + one action; Protocols = *do* that weather (timed plan). Cross-link both ways with matching copy.

## 3. IA cuts for a lively P0 (keep / cut / demote)
| Keep above fold | Demote / collapse | Cut from P0 surface |
|---|---|---|
| As-of + Indication echo (or deep-link to Today) | Natal baseline (collapsed; never longer than Today) | Duplicate Do/Don’t if lead already lists actions |
| One **Today** hero: 1 main action + Morning/Midday/Evening (owned items first) | Transit stacks → labeled “Why these stacks” under sky note | Standing “for every Type” habits on the week card |
| Sky · today/week **one** note (gates spelled Gate N · line L) | Emphasize / Pause lists | Decorative ☐ without persistence — either real checks or drop |
| Refresh with generated-at | Inventory (keep accessible, not competing with Today) | Second full restatement of Strategy/Authority in every block |

**P0 shape (one screen story):**  
`Weather (why today) → Do today (checkable) → This week (theme + sky only) → Natal (reference) → Inventory`

## Contrast note
Today already feels like a day (timestamp, Hyper, Focus corner, gates, Open Protocols). Protocols does not answer that invitation — redesign should **close the loop**, not invent a third OS pamphlet.
